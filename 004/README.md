# 阿哈 Maker 研究周报 · 第 004 期

**2026-10-09**

这一期最有意思的是把“看得见的运动”和“看不见的微观世界”放在一起：齿轮告诉孩子力怎样传递，显微镜让他们发现肉眼看不到的结构，灯具则把3D打印变成一件可以长期使用的产品。

## [Gearfinity：一转就停不下来的机械传动玩具](https://github.com/gearfinity/gearfinity)

齿轮、曲柄和连杆拼在一起，转动一个零件，其他零件会按照固定关系运动。孩子不需要先学公式，就能通过观察大小齿轮的速度差理解传动比。

**它怎么做？** 3D打印几组齿数不同的齿轮，组装成可更换的传动模块。用标记点记录输入轴与输出轴转数，再比较实际比值。

**可以怎样上课？** 9岁以上，4—8课时。基础课做齿轮玩具，进阶加入曲柄滑块、减速机构和参数化CAD。

**先验证什么？** 先打印三组齿轮，检查啮合、轴孔公差和重复转动磨损；夹手点需要防护。

## [OpenFlexure：自己打印一台显微镜](https://openflexure.org/)

显微镜把光学、精密运动与3D打印连接起来。最有价值的地方是它的柔性机构：通过材料自身的微小弹性变形实现精细调节，而不完全依赖传统滑轨。

**它怎么做？** 先确定官方硬件版本与镜头、相机和照明方案，打印关键结构并检查装配精度。采集图像时用刻度样片验证视场和重复性。

**可以怎样上课？** 10岁以上，6—16课时。低龄做显微观察与图像记录，高龄研究焦距、分辨率、微调机构和Python图像处理。

**先验证什么？** 先核对完整BOM与版本兼容性，不把未校准的照片直接当作定量测量结果。

## [Voronoi Lamp：把数学图案变成一盏灯](https://github.com/sayantanauddy/voronoi-lamp)

Voronoi图案像细胞或裂纹一样把表面分割成许多区域。把它打印成镂空灯罩后，光影会把数学结构投射到墙上。

**它怎么做？** 设计和打印镂空外壳，安装低压LED，观察壁厚、孔洞大小与光扩散的关系。

**可以怎样上课？** 8岁以上，2—8课时。体验版修改图案和颜色，进阶版学习Voronoi生成、参数化建模与散热设计。

**先验证什么？** 先做低压样机，测试温升、结构强度和光源固定，避免高温灯泡。

## [Rubik Robot：让机器人自己解魔方](https://github.com/twinone/rubik-robot)

自动解魔方把视觉识别、状态表示、求解算法与机械执行放在同一个作品里。看似只是转动魔方，实际上每一步都需要精准对齐。

**它怎么做？** 先做颜色识别与状态编码，再分开验证转动机构和动作序列；最后才组合求解流程。

**可以怎样上课？** 12岁以上，8—12课时。适合算法、机械与视觉的综合项目。

**先验证什么？** 先核实夹持机构和转动可靠性，避免高速夹手与卡死。

## [LeLamp：像机器人一样回应人的灯](https://github.com/humancomputerlab/LeLamp)

多轴灯具把照明产品变成互动机器人。孩子可以思考灯为什么要转头，以及怎样表达“关注”。

**它怎么做？** 先做单轴灯头与低压光源演示，再逐步加入交互。

**可以怎样上课？** 适合高阶交互设计和机构观察。

**先验证什么？** 不直接复制外观商用，先查许可和电气安全。

## [Q8bot：把电路板也当作机械结构](https://github.com/EricYufengWu/q8bot)

PCB不只是电路载体，也可能成为机器人结构的一部分。这种思路有助于理解产品小型化和结构—电路一体设计。

**它怎么做？** 观察板材刚度、连接方式和关节结构。

**可以怎样上课？** 高阶教师研究，适合引导PCB与CAD跨学科讨论。

**先验证什么？** 先核查板图、器件和加工可得性。

## 接下来先做什么

第一优先制作三组Gearfinity齿轮并记录传动比；同时做Voronoi低压灯样机。OpenFlexure先确定版本、镜头与BOM，再决定是否作为班级共用设备。
