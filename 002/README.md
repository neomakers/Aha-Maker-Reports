## 决策摘要

主题：桌面自动化工厂、机械臂与互动灯具。优先选择可以通过3D打印、激光切割和常见控制器制作的项目。成本等级和商业复用条款须以采购及作者最新许可为准。

## A. 值得研究并课程化

### AutoSort ESP32

- 原始资料：https://github.com/itspdp/AutoSort-ESP32-Robotic-Arm
- 研究价值与课程建议：颜色传感器、输送带与机械臂的桌面分拣系统；建议11岁以上、8–12课时；中高成本，优先测试抓取成功率。

## 本周课程开发计划

P0：Laser LED Art制作低压安全展示样机；P1：AutoSort先完成颜色识别+机械抓取20次循环，达标后再加入输送带。

**教师验收通用要求：**先复核BOM和供电安全，记录实际制作工时、成本与失效情况；至少进行一轮教师独立复现和试教，再决定是否进入收费课程。
