# 阿哈 Maker 研究周报 · 第 002 期

**2026-09-25**

这期有两条很不一样的路线：一条让桌面设备像小工厂一样分拣物品，另一条让激光切割的板材变成有层次的灯光作品。前者适合系统工程课，后者更适合短时间内做出能带回家的作品。

## [Laser-cut LED Art：把亚克力和木板做成发光艺术](https://learn.adafruit.com/laser-cut-layered-led-art-panel-wood-acrylic-with-wled)

多层切割板材、透光材料和LED叠在一起，光会被遮挡、散射、反射，形成比单层平面更丰富的视觉效果。孩子可以直接看到材料与形状如何改变光。

**它怎么做？** 使用激光切割准备层叠面板和框架，再用WLED控制灯光颜色、亮度与动画。先用低压电源和教师预制接线，重点留给孩子做图案、排版和组装。

**可以怎样上课？** 8岁以上，2—6课时。体验版选一幅图案并装灯，标准版自己绘制矢量轮廓，进阶版修改灯光动画。可以把数学中的对称与图层概念加入设计。

**先验证什么？** 先做一套安全展示样机，验证材料透光、散热、固定方式和装配时间；不要让儿童独立操作未防护激光设备。

## [AutoSort ESP32：桌面上搭一条迷你分拣线](https://github.com/itspdp/AutoSort-ESP32-Robotic-Arm)

传感器识别颜色，输送机构把物体送到指定位置，机械臂再抓起并放入不同区域。这就是一个缩小版的自动化工厂，适合解释感知、决策和执行如何连接。

**它怎么做？** 不要第一天就把输送带、机械臂、颜色识别全部接起来。先验证颜色识别，再让机械臂完成固定点抓放，最后才把两个子系统联动。

**可以怎样上课？** 11岁以上，8—12课时。先做红蓝绿识别，再做抓放路径，最后加入计数、故障处理和简单产线节拍统计。

**先验证什么？** 先完成20次固定位置抓放，记录成功率与误抓原因；再引入输送带。注意夹手点、急停和电源保护。

## [Pedro Robot：从打印零件组装教育机械臂](https://github.com/almtzr/Pedro)

机械臂是很直观的空间运动学教具。孩子旋转一个关节，末端会沿一条弧线运动；几个关节一起改变，抓手才能到达目标。

**它怎么做？** 先按原项目核对可打印零件、舵机型号和紧固件。装配时重点观察转轴同心度、齿轮间隙与关节活动范围。

**可以怎样上课？** 9岁以上，4—8课时。低龄以组装和遥控为主，高龄加入坐标、角度、顺序控制和抓取挑战。

**先验证什么？** 打印关键承力件，确认舵机回差和末端负载；若重复定位不稳定，先降低抓取任务难度。

## [LightComposer：旋钮能不能成为灯光乐器？](https://johnengeln.com/projects/lightcomposer/)

把旋钮变成创作界面：每次转动改变光的颜色、速度或图案。它可以启发一个不依赖屏幕的互动艺术作品。

**它怎么做？** 先用一两个旋钮控制RGB灯，再加入预设场景与保存功能。

**可以怎样上课？** 适合作为电子交互与状态机的小型体验课。

**先验证什么？** 原项目的可复用硬件文件与授权需单独核对。

## [PrintPupper：从桌面玩具走向四足机器人](https://www.printpupper.com/)

四足机器人的魅力在于它真的需要解决稳定、运动和控制问题。适合用来展示更高阶的工程挑战。

**它怎么做？** 先拆解机械腿、关节和控制架构，不直接作为低龄套件采购。

**可以怎样上课？** 面向高阶教师研究，未来可衍生单腿步态实验。

**先验证什么？** 整机成本、备件与安全保护未核实前不承诺开课。

## 接下来先做什么

先完成一件低压LED层叠艺术展示样机；自动分拣线分三阶段测试，先识别，再抓取，最后联动。课程开发时分别记录制作工时、材料成本和失败原因。
