## 决策摘要

主题：桌面机器人、绘图机构与创客入门。优先选择可以通过3D打印、激光切割和常见控制器制作的项目。成本等级和商业复用条款须以采购及作者最新许可为准。

- 原始资料：https://github.com/jamro/tiny-engineer
- 研究价值与课程建议：ESP32-C3、5舵机与OLED的桌面机器人；适合AI辅助编程和动作控制，建议12岁以上、6–10课时；成本中等，先验证供电、机械行程和动作重复性。

## 本周课程开发计划

P0：先打印PenBot Mini关键件，测试连续绘制20次的精度；P1：Stack-chan教师样机，验证表情、触摸、动作状态机。

**教师验收通用要求：**先复核BOM和供电安全，记录实际制作工时、成本与失效情况；至少进行一轮教师独立复现和试教，再决定是否进入收费课程。
