# 阿哈 Maker 研究周报 · 第 001 期

**2026-09-18**

这期的关键词是“让作品有性格”。孩子看到一个机器人转头、眨眼、画出自己的名字，往往比看电路图更愿意追问：它为什么知道该怎么动？建议先做绘图机构，再做有表情的桌面机器人。

## [PenBot Mini：用机械臂画出自己的名字](https://github.com/dorianborian/penbot-mini)

先看一支笔怎样在纸面移动。绘图机构把电机转角变成笔尖的位置，程序给出一串坐标，机构再按顺序走过去。它把抽象的坐标、比例和运动学变成可以拿在手里的图案。

**它怎么做？** 用ESP32控制绘图机构，先校准笔尖的原点和纸张范围，再画直线、正方形与名字。难点通常不在画图代码，而在笔尖抬落、舵机间隙和重复定位。

**可以怎样上课？** 11岁以上，6—8课时。第一节手动找坐标，第二节画基本图形，随后让学生用Python或简单图形程序生成轨迹；进阶讨论连杆长度、角度和误差。

**先验证什么？** 先打印关键零件，连续绘制同一图形20次，比较位置漂移。若笔尖晃动太大，先缩小工作范围，不急着加复杂图案。

## [Stack-chan：能转头、能表达情绪的桌面伙伴](https://github.com/stack-chan/stack-chan)

这是一条很适合低门槛展示的机器人路线。显示屏负责表情，舵机负责转头和点头，输入事件决定它何时回应。学生不必一开始就理解复杂AI，也能做出一个有互动感的作品。

**它怎么做？** 使用M5Stack相关控制硬件、显示屏和舵机，软件把按钮、传感器或消息映射成表情和动作。实际硬件版本与外壳必须按选定分支核对，不能把不同教程的配件直接混装。

**可以怎样上课？** 9岁以上，4—8课时。先完成三种表情和三种动作，再把触摸、距离或声音作为触发条件。进阶可以设计自己的机器人角色与英语问候语。

**先验证什么？** 教师先验证舵机转角限位、供电与外壳间隙；至少测试20次状态切换，确保不会卡住。

## [Tiny Engineer：把多个关节装进小机器人](https://github.com/jamro/tiny-engineer)

它比单个舵机玩具更接近真正的机器人系统：多个关节协同运动，屏幕或显示组件负责反馈。孩子可以从“一个动作”理解到“一组动作如何配合”。

**它怎么做？** 项目涉及ESP32-C3、多个舵机与OLED。建议先做动作序列：抬手、转向、停顿、恢复，而不是直接承诺复杂自主行为。电源瞬态电流和机械限位是第一轮测试重点。

**可以怎样上课？** 12岁以上，6—10课时。可把动作编成故事或小游戏，进阶讨论状态机、插值和多关节同步。

**先验证什么？** 先验证单舵机，再逐个增加关节；记录最大电流、复位现象和重复动作偏差。

## [Sesame Robot：四足行走的机械灵感](https://github.com/dorianborian/sesame-robot)

四条腿为什么能走路？这个项目适合用来观察足端轨迹、支撑与摆动的区别。它的价值在于激发机构设计问题，不必作为第一门机器人课。

**它怎么做？** 先观察机械腿和关节配置，再用纸板或打印件制作单腿演示模型，理解关节联动。

**可以怎样上课？** 高阶教师样机或12岁以上专题。可先讲步态与稳定性，再进入完整四足系统。

**先验证什么？** 整机采购前先核对零件、舵机负载与跌倒保护。

## [Foxie Clock：自己设计一只会发光的时钟](https://github.com/afoxinsocks/foxie-clock)

把数字时间变成一个有外观、有光效的产品，是很好的“设计—制作—使用”练习。

**它怎么做？** 研究RGB灯、时间显示与外壳装配的关系，鼓励学生做原创外观。

**可以怎样上课？** 适合作为跨学科产品设计灵感。

**先验证什么？** 先检查时间保持、亮度和供电安全。

## 接下来先做什么

优先打印PenBot Mini的关键件，建立重复绘制记录；第二优先做Stack-chan的三表情三动作教师样机。先让作品稳定完成一个小任务，再增加AI和复杂交互。
