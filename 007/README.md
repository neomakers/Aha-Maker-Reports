本周的两个新增信号  
信号一：小件模块化  Adafruit在10月27日发布12颗可插接NeoPixel的打印花环：课程不一定要焊接才能讲懂控制与机构。它是“形状设计×灯效×软件配置”一体的较好范式。[S01—S04]  
信号二：低成本机器人路线  新4WD项目在10月27日创建，10月28日被报道。其浏览器地图和超声波探测很吸引人，但缺少编码器/标准SLAM估计链，不宜把学生的课程目标直接写成“实现成熟SLAM”。[S05—S07]  
决策结论  
第一件事：做一个12像素的“可更换主题灯饰”教师样机，2—4节课内让学生从外壳到灯效完成闭环。第二件事：让探路车先完成“停障—扫描—位置记录—网页显示”，最后再讨论地图漂移。第三件事：Skylon与光谱仪先做可行性预研，禁止承诺未经校准的定量准确度。

03  A类｜直接进入课程研发的项目  
A01  模块化动态灯饰：NeoPixel Brick Holiday Wreath  
A01  /  P0   |   本周官方新教程   |   作者教程发布 2026-10-27  
项目定位：这是由Adafruit Ruiz Brothers发布的3D打印可拼装灯饰。官方使用Sparkle Motion Mini（ESP32）、12个JST插接NeoPixel发光模块、连接线和可打印的枝条/扩散器结构；WLED直接提供网页灯效和音乐响应。官方说明无需焊接，结构允许修改节庆外观。[S01—S04]  
	核查维度  
	结论 / 待核项  
  
	制造资料  
	官方教程分设CAD Files、Assembly与Circuit Diagram；模块化打印零件可定位。  
  
	程序与接口  
	WLED可通过浏览器配置；ESP32板预置WLED可减少初级编程门槛。  
  
	许可  
	WLED代码仓库为EUPL-1.2；Adafruit本项目CAD/图像的独立商用条款尚待最终确认。  
  
	成本证据  
	官方显示像素模块$1.50×12，JST连接线$1.75×11，5V/1A电源$5.95，USB线$2.95；仅上述部分合计$46.15，未含主控、额外转接线、紧固件、打印和运输；报价仅为核查时网页显示，不是整套成本。  
  
	课堂难点  
	原版模块与专用线供应、打印卡扣公差、图形主题同质化、电源和快速闪烁效果。  
  
  
  
阿哈改造方案：做“主题可替换的互动灯饰”  
〔建议〕将节庆花环改造成四个可更换主题：星空、花草、房屋与姓名。低龄班先拼装和改灯效，高年龄班改成自己的CAD图案、编写WLED API或Python脚本；可用英语描述灯光效果，由AI生成第一版，再让学生验证。适合8—13岁；体验2节，正式4—6节。

A02  超声波探路车：4WD SLAM Radar 2D Robot Car  
A02  /  P1   |   2026-10-27创建，10-28媒体报道   |   新项目但性能未经独立复现  
作者Luca Fagioli使用Arduino UNO R4 WiFi、4WD TT电机底盘、L298N、SG90舵机、HC-SR04超声波和底部3个IR传感器；通过网页展示扫描结果、车辆状态与二维墙体示意。仓库可见Arduino源码、map.html和GPL-3.0许可证，但未见完整可打印底盘CAD。[S05—S07]  
特别核查：原作者将系统称作SLAM，但README也明确指出无车轮编码器。现有资料更适合被描述为“低成本超声波环境扫描＋基于地面路标的运动估计和网页可视化”；尚无证据证明它达到标准SLAM定位精度或鲁棒性。  
	复现事项  
	教学团队应采取的决定  
  
	硬件  
	复用现成4WD底盘；先做有线调试，不急于3D打印原创底盘。  
  
	软件  
	单独运行“测距—转向—距离阈值停车—Web地图”；不要同时整合全部功能。  
  
	安全  
	两种供电必须按作者线路处理并共地；18650电池由教师保护性安装与充电，不由儿童裸接。  
  
	教学目标  
	正确描述“测量误差、漂移、路标校正”，而非宣称课堂实现完整自动驾驶。

A03  桌面风洞：Skylon V1  
A03  /  P1   |   存量开源项目补挖   |   非本周首发  
Skylon V1将风道结构、教学Arduino采集与Python可视化放进一个仓库，明确具有BOM、Fusion 360 F3Z、STEP、STL、装配说明、Arduino Uno/Nano双BMP180采集程序及Python仪表盘。仓库标注MIT许可证，并直言数据“仅具演示性质、尚未校准”。[S08—S10]  
教学价值：它使“空气流动”不再只依赖视频：学生可以先预测不同风道或纸翼放置的压力变化，再画图、反思误差、迭代结构。适合11—16岁，建议6—10课时；英语可作为工程报告语言，AI可帮助解释趋势但不得冒充实验校准。

A04  3D打印光纤光谱仪：GaudiLabs  
A04  /  P2   |   经典科研Maker项目   |   非本周首发  
GaudiLabs的3DFiberSpectrometer使用光纤引光、衍射光栅分光和小型USB摄像头成像，电脑可以看到光谱强度变化。主仓库公开打印结构与比色皿支架目录，并带GPL-3.0许可证；另有基于网页的光谱查看项目。[S11—S13]  
课程建议：先从白光、彩色LED、光栅得到彩虹开始；再学习相机图像采集与“波长—像素”标定。对教学效果的判断主要依赖实际光路对准和器件能否稳定采购，不能只看模型文件就认定课程成熟。建议11—16岁，基础4节、正式6—8节。

B01  realisticPM：超大号PM2.5空气质量显示器  
B01   |   本周10-27 Hackaday报道   |   作者项目不等于当日首发  
原作者WeSpeakEnglish使用XIAO SAMD21、SPS30或Panasonic颗粒物传感器和大型LED七段板，把室内PM读数做成远距离可读的实时装置；还提供USB串口数据输出。GitHub可定位PCB/机械/Arduino文件，但根目录未发现独立LICENSE，故不能把“公开源码”写成“允许商用改编”。[S14—S15]

B02  Marble Scroller：用黑白弹珠“打印”滚动文字  
B02   |   2026-10-25媒体报道   |   原设计尚未核实完整可复用制造文件  
Iván Miranda制作巨型3D打印机械滚筒，通过内外步进机构分选黑白弹珠，在旋转结构上形成滚动字形。报道明确提到日光干扰IR检测、需要手动归零、弹珠比例影响字形等实际缺陷。[S16]  
阿哈价值：一个令人愿意围观的机械显示装置，适合讨论“像素、二进制、球体供料、传感器、故障排查”。不建议按原型直接复刻：体积过大、资料许可未验证、课堂安全难度高。可原创制作3×5孔位的机械像素样板作为概念验证；适合13岁以上高阶展示与机构研究。  
原始资料：Hackaday原文 [S16]  
B03  SpooBu：靠重力自动回卷的3D打印料盘机构  
B03   |   经典机械项目补挖   |   非本周首发  
kevinakasam的SpooBu使用计重锤和齿轮，耗材放线时抬升配重；回抽时利用重力回转料盘。GitHub包含参数化CAD、STL、GPL-3.0许可与演示说明，作者也在README承认BOM尚未完整整理；至少需要3个608轴承、M8螺栓等。是一个很适合3D打印实验室的“真正有功能的机械”。[S17—S18]  
阿哈改造：先用小型手动演示件展示能量储存、重力势能与齿轮传动，再面向高阶班讨论FDM送料阻力和打印质量。10—16岁，2节原理课＋3—4节参数化结构课。设备适配真实打印机前必须做线材不缠绕与回卷张力测试；GPL衍生文件分发需遵守相应义务。  
原始资料：SpooBu CAD / STL / 许可仓库 [S17]

教学路径：从作品到知识  
体验层：孩子先让“东西动起来/亮起来” → 原理层：理解机械、电学和数学模型 → 编程层：自己调整参数、读取数据 → AI协作层：让AI生成初版设计与代码、由学生测试并写出验证结果。英语融入项目名称、器件文档与设计日志，而不是额外叠加一节脱节的英语课。
