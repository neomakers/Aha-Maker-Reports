## [NeoPixel Brick Wreath：可换主题的互动灯饰](https://learn.adafruit.com/holiday-brick-wreath)

NeoPixel Brick Holiday Wreath

项目定位：这是由Adafruit Ruiz Brothers发布的3D打印可拼装灯饰。官方使用Sparkle Motion Mini（ESP32）、12个JST插接NeoPixel发光模块、连接线和可打印的枝条/扩散器结构；WLED直接提供网页灯效和音乐响应。官方说明无需焊接，结构允许修改节庆外观。

制造资料

官方教程分设CAD Files、Assembly与Circuit Diagram；模块化打印零件可定位。

程序与接口

WLED可通过浏览器配置；ESP32板预置WLED可减少初级编程门槛。

许可

WLED代码仓库为EUPL-1.2；Adafruit本项目CAD/图像的独立商用条款尚待最终确认。

成本证据

官方显示像素模块$1.50×12，JST连接线$1.75×11，5V/1A电源$5.95，USB线$2.95；仅上述部分合计$46.15，未含主控、额外转接线、紧固件、打印和运输；报价仅为核查时网页显示，不是整套成本。

课堂难点

原版模块与专用线供应、打印卡扣公差、图形主题同质化、电源和快速闪烁效果。

阿哈改造方案：做“主题可替换的互动灯饰”

将节庆花环改造成四个可更换主题：星空、花草、房屋与姓名。低龄班先拼装和改灯效，高年龄班改成自己的CAD图案、编写WLED API或Python脚本；可用英语描述灯光效果，由AI生成第一版，再让学生验证。适合8—13岁；体验2节，正式4—6节。

## [4WD Radar Robot：会探路的小车](https://github.com/lucaeffe03/4WD-SLAM-Radar-2D-Robot-Car)

4WD SLAM Radar 2D Robot Car

作者Luca Fagioli使用Arduino UNO R4 WiFi、4WD TT电机底盘、L298N、SG90舵机、HC-SR04超声波和底部3个IR传感器；通过网页展示扫描结果、车辆状态与二维墙体示意。仓库可见Arduino源码、map.html和GPL-3.0许可证，但未见完整可打印底盘CAD。

特别核查：原作者将系统称作SLAM，但README也明确指出无车轮编码器。现有资料更适合被描述为“低成本超声波环境扫描＋基于地面路标的运动估计和网页可视化”；尚无证据证明它达到标准SLAM定位精度或鲁棒性。

复现事项

教学团队应采取的决定

硬件

复用现成4WD底盘；先做有线调试，不急于3D打印原创底盘。

软件

单独运行“测距—转向—距离阈值停车—Web地图”；不要同时整合全部功能。

安全

两种供电必须按作者线路处理并共地；18650电池由教师保护性安装与充电，不由儿童裸接。

教学目标

正确描述“测量误差、漂移、路标校正”，而非宣称课堂实现完整自动驾驶。

## [Skylon：3D打印桌面风洞](https://github.com/RevanBamoki/skylon-wind-tunnel)

Skylon V1

Skylon V1将风道结构、教学Arduino采集与Python可视化放进一个仓库，明确具有BOM、Fusion 360 F3Z、STEP、STL、装配说明、Arduino Uno/Nano双BMP180采集程序及Python仪表盘。仓库标注MIT许可证，并直言数据“仅具演示性质、尚未校准”。

教学价值：它使“空气流动”不再只依赖视频：学生可以先预测不同风道或纸翼放置的压力变化，再画图、反思误差、迭代结构。适合11—16岁，建议6—10课时；英语可作为工程报告语言，AI可帮助解释趋势但不得冒充实验校准。

## [GaudiLabs：3D打印光谱仪](https://github.com/GaudiLabs/3DFiberSpectrometer)

光谱仪：GaudiLabs

GaudiLabs的3DFiberSpectrometer使用光纤引光、衍射光栅分光和小型USB摄像头成像，电脑可以看到光谱强度变化。主仓库公开打印结构与比色皿支架目录，并带GPL-3.0许可证；另有基于网页的光谱查看项目。

课程建议：先从白光、彩色LED、光栅得到彩虹开始；再学习相机图像采集与“波长—像素”标定。对教学效果的判断主要依赖实际光路对准和器件能否稳定采购，不能只看模型文件就认定课程成熟。建议11—16岁，基础4节、正式6—8节。

## [realisticPM：会显示空气颗粒的装置](https://github.com/WeSpeakEnglish/realisticPM)

超大号PM2.5空气质量显示器

原作者WeSpeakEnglish使用XIAO SAMD21、SPS30或Panasonic颗粒物传感器和大型LED七段板，把室内PM读数做成远距离可读的实时装置；还提供USB串口数据输出。GitHub可定位PCB/机械/Arduino文件，但根目录未发现独立LICENSE，故不能把“公开源码”写成“允许商用改编”。

阿哈价值：可转化为“教室环境数据显示器”，让学生学习I²C、数据采集、数字读数、图形编码和统计。适合10—15岁，原创简化版4—6节；应自研外壳与固件，作为科普监测装置，不得代替合规空气检测设备，也不要把传感器读数等同于医学安全判定。

## [Marble Scroller：弹珠组成的滚动文字](https://hackaday.com/2026/10/25/a-3d-printed-marble-clock-but-its-scrolling-text/)

Scroller：用黑白弹珠“打印”滚动文字

Iván Miranda制作巨型3D打印机械滚筒，通过内外步进机构分选黑白弹珠，在旋转结构上形成滚动字形。报道明确提到日光干扰IR检测、需要手动归零、弹珠比例影响字形等实际缺陷。阿哈价值：一个令人愿意围观的机械显示装置，适合讨论“像素、二进制、球体供料、传感器、故障排查”。不建议按原型直接复刻：体积过大、资料许可未验证、课堂安全难度高。可原创制作3×5孔位的机械像素样板作为概念验证；适合13岁以上高阶展示与机构研究。

## [SpooBu：用重力自动回卷的料盘](https://github.com/kevinakasam/SpooBu)

靠重力自动回卷的3D打印料盘机构

kevinakasam的SpooBu使用计重锤和齿轮，耗材放线时抬升配重；回抽时利用重力回转料盘。GitHub包含参数化CAD、STL、GPL-3.0许可与演示说明，作者也在README承认BOM尚未完整整理；至少需要3个608轴承、M8螺栓等。是一个很适合3D打印实验室的“真正有功能的机械”。

阿哈改造：先用小型手动演示件展示能量储存、重力势能与齿轮传动，再面向高阶班讨论FDM送料阻力和打印质量。10—16岁，2节原理课＋3—4节参数化结构课。设备适配真实打印机前必须做线材不缠绕与回卷张力测试；GPL衍生文件分发需遵守相应义务。

课程组必须收集的数据

每台样机建立一张《研发记录卡》：Git仓库与commit SHA、依赖版本、BOM币种/报价日期、打印时间与材料克重、装配人数与时长、故障及修复、可复制结果次数、8—12岁实际操作比例（若做试教）、许可证明链接。这样以后同一课程不会因为教师换人就无法复现。

教学路径：从作品到知识

体验层：孩子先让“东西动起来/亮起来” → 原理层：理解机械、电学和数学模型 → 编程层：自己调整参数、读取数据 → AI协作层：让AI生成初版设计与代码、由学生测试并写出验证结果。英语融入项目名称、器件文档与设计日志，而不是额外叠加一节脱节的英语课。
