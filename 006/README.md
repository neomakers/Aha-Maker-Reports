## [Sandify：会画画的数学沙盘](https://sandify.org/)

与轨迹

课程定位： 10 岁以上做图案与参数；12 岁以上加入机械控制。首轮 2 节软件课，实机扩展再增加 4—6

节。不预先采购整套沙盘。

技术边界：轨迹生成与执行是两件事

Sandify 的核心是生成适合钢球绘图的连续、有边界轨迹，并导出到相应设备。软件采用 MIT 许可，但

LICENSE 明确把 Logo 资源排除在该许可之外。它不是完整机械制造包。 Dune Weaver 是另一条可参考的实现路线：树莓派负责界面/图案处理，ESP32 类控制器运行运动固件；

其示例采用 Theta/Rho 极坐标，不是把任意 XY 轨迹直接发送即可。该项目许可说明还并列商业许可条

款，不能仅凭仓库 GPL 标签作完整复用判断。 阿哈的最小可行课程

作品目标：让一条连续轨迹形成可解释的图案。 第一节用 Sandify 改变形状、重复次数和边界；第二节

用 Python 生成简单螺旋，并比较预览与导出数据。软件阶段不需要沙盘，电脑和浏览器即可开展。

进阶版才增加运动平台、两个步进电机及驱动、控制器、限位/归零方案、磁铁钢球、盘体与防护结构。

平台尺寸、控制器与坐标形式确定后，再编制对应 BOM；不能拼接几个仓库就称为完整套件。

电流与外壳温度。学生须能独立修改一个图案并解释数据变化。温度与电气安全上限应由教师按器件资

料设定，以上测试不替代安全评估。

图案和检查 JSON，但显示逻辑、尺寸与亮度由教师约束；不把“自动生成”当作理解证明。

03 A 类｜数学沙画与轨迹

课程定位： 10 岁以上做图案与参数；12 岁以上加入机械控制。首轮 2 节软件课，实机扩展再增加 4—6

节。不预先采购整套沙盘。

技术边界：轨迹生成与执行是两件事

Sandify 的核心是生成适合钢球绘图的连续、有边界轨迹，并导出到相应设备。软件采用 MIT 许可，但

LICENSE 明确把 Logo 资源排除在该许可之外。它不是完整机械制造包。

Dune Weaver 是另一条可参考的实现路线：树莓派负责界面/图案处理，ESP32 类控制器运行运动固件；

其示例采用 Theta/Rho 极坐标，不是把任意 XY 轨迹直接发送即可。该项目许可说明还并列商业许可条

款，不能仅凭仓库 GPL 标签作完整复用判断。

阿哈的最小可行课程

作品目标：让一条连续轨迹形成可解释的图案。 第一节用 Sandify 改变形状、重复次数和边界；第二节

用 Python 生成简单螺旋，并比较预览与导出数据。软件阶段不需要沙盘，电脑和浏览器即可开展。

进阶版才增加运动平台、两个步进电机及驱动、控制器、限位/归零方案、磁铁钢球、盘体与防护结构。

平台尺寸、控制器与坐标形式确定后，再编制对应 BOM；不能拼接几个仓库就称为完整套件。

已核实的能力与版本约束

OpenScan Mini 通过摄影测量采集照片，官方描述约 9 厘米级扫描空间、树莓派控制及环形照明；照片

还需交给重建软件处理。官网将精度与样品准备、使用者能力关联，不能把展示精度直接写成课堂保

证。

设计仓库区分 Mini V1 与 V2，列出不同 BOM 和电子配置；OpenScan2 固件仓库标记 GPL-3.0。制造模

型、PCB 与处理服务仍需各自检查许可和版本，本次没有完成全部制造文件的授权核查。

关键问题不是“会不会转”，而是“能否完成闭环”

阿哈的目标应为：拍照 → 重建 → 定尺度 → 清理网格 → 切片 → 打印 → 测量误差。 若只做转台拍照演

示，无法兑现数字制造课程的核心价值。最易低估的是重建时间、模型缺孔、比例校准与老师逐台补救

的时间。

教师先选三种小型哑光、纹理明显的安全样品；反光或透明对象留作进阶失败案例。提前确定本地重建

软件和算力；采用云服务时单独核对访问、数据处理与使用条件。课堂仅采集作品，不默认上传儿童面

部或个人物品数据。
