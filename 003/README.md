# 阿哈 Maker 研究周报 · 第 003 期

**2026-10-02**

这一期适合做两类作品：一类是孩子能马上理解的绘图机器人和电子宠物；另一类是展示AI如何控制真实硬件的实验。建议把“作品能不能稳定运行”放在“看起来智能不智能”前面。

## [BrachioGraph：用几根木棒做一台绘图机器人](https://github.com/evildmp/BrachioGraph)

这类绘图机器人特别适合课堂：几根连杆、两个舵机、一支笔，就能把程序里的坐标变成纸上的线。孩子可以自己观察圆弧、误差和比例变化。

**它怎么做？** 树莓派控制舵机，连杆长度与舵机角度决定笔尖位置。先做原点校准、线段和方形，再画字母与图案。

**可以怎样上课？** 9岁以上，6—10课时。Python负责生成轨迹，数学课讨论角度、坐标和比例，英语课可以用机器人画单词。

**先验证什么？** 教师先制作可重复校准的样机，测量20次同图绘制的偏差，保留校准参数。

## [TamaFi：给ESP32做一只电子宠物](https://github.com/cifertech/TamaFi)

一只会饿、会开心、会睡觉的电子宠物，本质上是一个可视化状态机。它特别适合把变量、时间、条件判断和概率讲得不抽象。

**它怎么做？** 用ESP32和小屏幕显示动画，按钮或其他输入改变宠物状态。先实现饥饿值、心情和三种动画，再增加时间与随机事件。

**可以怎样上课？** 9岁以上，4—10课时。基础版改表情和规则，进阶版设计宠物成长曲线、数据保存与自己的像素角色。

**先验证什么？** 优先做低成本ESP32+TFT样机，连续运行并检查状态保存、按键抖动和断电恢复。

## [MeArm：让机械臂抓起第一块积木](https://github.com/MeArm/MeArm)

激光切割板材组装的机械臂，让孩子看见关节运动与末端位置的关系。抓起一个小物体比复杂轨迹更容易建立成就感。

**它怎么做？** 核对板材厚度、舵机规格和装配间隙；从单关节控制逐步增加到抓取动作。

**可以怎样上课？** 9岁以上，8—10课时。可以设计积木搬运挑战，进阶学习逆运动学和动作序列。

**先验证什么？** 先用轻质物体测试，限制夹持力，检查结构和舵机温升。

## [ESP32 GPIO LLM：让语言模型点亮一盏灯](https://github.com/manjunathshiva/esp32-gpio-llm)

这条路线适合讲AI与真实世界的边界：人说一句话，模型输出控制意图，程序检查后才执行。重点不是让AI直接控制一切，而是让孩子理解为什么需要验证。

**它怎么做？** 先用LED演示文本指令到GPIO的转换，加入白名单、确认步骤与错误指令测试。

**可以怎样上课？** 12岁以上，4—6课时。可以比较规则控制与模型控制的稳定性，记录误判案例。

**先验证什么？** 仅连接安全低压LED，不连接加热、运动或其他危险负载。

## [TNY-360：高阶四足机器人研究](https://github.com/TNY-Robotics/TNY-360)

适合教师观察机械腿、姿态与控制系统的组合方式。

**它怎么做？** 先查机械文件、电子架构与商业许可，再考虑制作。

**可以怎样上课？** 暂列高阶灵感，不作为低龄首批课程。

**先验证什么？** 许可可能存在商业使用限制，必须逐项核对。

## [KryonOS：把JavaScript带进ESP32](https://github.com/Haris16-code/KryonOS)

让嵌入式设备用更接近网页开发的方式编程，对熟悉JavaScript的高龄学生有启发。

**它怎么做？** 研究程序运行环境、GPIO能力与内存限制。

**可以怎样上课？** 适合13岁以上的编程工具观察。

**先验证什么？** 先核实版本兼容性和运行稳定性。

## 接下来先做什么
