## 每期有什么

每期围绕有意思的项目，介绍它是什么、为什么值得做、如何工作、怎么制作，以及怎样改造成孩子能够完成的课程。对于值得打样的项目，还会给出教师准备、课程升级路线和需要先验证的问题。

> 本资料库提供研究和课程设计参考；具体制作文件、器件版本与商业使用许可，以原作者项目说明为准。
