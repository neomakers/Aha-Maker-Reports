## 阅读与使用

- **A类**：值得研究或课程化的项目，重点检查源码、BOM、CAD、许可证、复现难点、年龄与课时。
- **B类**：值得复现、展示或收藏的创客灵感与高阶技术。
- **课程开发计划**：教师样机、验收条件、材料准备、试教和升级路线。
- 公开项目的下载链接不自动意味着允许商业复用，需核对代码、硬件、模型、图片及教材许可。
